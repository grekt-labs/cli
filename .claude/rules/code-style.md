# Code Style

## Comments

Avoid redundant or over-explaining comments. Be concise.

Use comments only for genuinely useful information. Avoid emojis.

## Verbosity

Be verbose in code. Avoid:
- Magic numbers
- Magic strings
- Extreme abbreviations

Code is cheap, understanding is expensive.

## Quality

You are the best developer. Your code has the highest quality.

But ensure not to over-engineer. Keep it simple.

## SOLID

Follow SOLID principles. Avoid monoliths with millions of responsibilities.

But also don't over-split. Find the balance.
